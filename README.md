# HRIS PT Artha Safety Indonesia

Portal HRIS: absensi selfie + GPS, cuti/izin, slip gaji, agenda, tugas dinas.

- **Versi lama (sementara):** https://managerartha.github.io/HRIS/ → backend Google Apps Script (`apps-script/Code.gs`).
- **Versi Hostinger:** `index.html` + backend PHP/MySQL di `api/`. Panduan lengkap: [DEPLOY-HOSTINGER.md](DEPLOY-HOSTINGER.md).

`index.html` yang sama otomatis memakai Apps Script saat dibuka dari `github.io`, dan memakai `api/index.php` saat dibuka dari domain Hostinger.
