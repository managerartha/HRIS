Pengaturan Lokasi GPS Kantor & Jam Kerja (WIB)

Tentukan titik Latitude, Longitude, batas radius, serta Jam Masuk dan Pulang kantor.

Di Google Maps: tekan lama (HP) / klik kanan (laptop) tepat di gedung → Bagikan / Share → Salin link, lalu tempel di sini. Latitude, longitude & area absen terisi otomatis.

Saran: minimal 30–50 meter. GPS HP di dalam gedung biasanya meleset 10–30 meter, radius 10 meter membuat karyawan yang sudah di kantor sering gagal absen.

Lingkaran hijau = area yang diizinkan untuk absen. Titik merah bisa digeser untuk menyesuaikan posisi.

Hari kerja Senin–Sabtu. Hari Minggu & tanggal merah tidak dihitung Alpha; kerja di hari tersebut dihitung lembur hari libur.

Backup Data HRIS

Download seluruh data (akun karyawan, absensi, pengajuan, slip gaji, agenda, dinas) dalam satu file ZIP. Isi: file CSV per tabel (bisa dibuka di Excel) + file hris.sql untuk mengembalikan data lewat phpMyAdmin.

Data juga bisa dilihat langsung di hPanel Hostinger → Databases → phpMyAdmin (tabel users berisi akun karyawan).
